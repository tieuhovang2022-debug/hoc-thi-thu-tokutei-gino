# Học & Thi Thử Tokutei Gino — Dương Giàn Giáo

Web học và thi thử Tokutei Gino (Kỹ năng đặc định) cho người Việt tại Nhật, đủ 3 ngành × Gino 1 & Gino 2, đúng format đề thi chính thức (OTAFF / JAC):

- **Ngành Nhà Hàng**: 17 bài giảng + 20 đề thi thử (1.000 câu)
- **Ngành Thực Phẩm**: 13 bài giảng + 20 đề thi thử (900 câu)
- **Ngành Xây Dựng** (3 phân ngành Thổ mộc / Kiến trúc / Hạ tầng–Thiết bị): 21 bài giảng + 60 đề thi thử (3.450 câu)

Tổng cộng: **51 bài giảng và 100 đề thi thử — 5.350 câu hỏi**, tất cả có giải thích tiếng Việt. Phòng thi mô phỏng CBT: bấm giờ, lưới câu hỏi, đánh dấu câu xem lại, chấm theo trọng số / theo từng phần và kết luận ĐỖ / CHƯA ĐỖ theo mốc chính thức.

## Cách dùng

Tải toàn bộ repo này về (nút **Code → Download ZIP**), giải nén, rồi mở file `index.html` trong trình duyệt là dùng được ngay — không cần cài đặt, không cần mạng.

Các file `data-*.js`, `app.js`, `img-*.js` là dữ liệu và mã chạy của web, phải để **cùng thư mục** với `index.html`.
